# Workspace Rules

- **Frontend Scope**: The project must remain completely frontend-focused. Do not spin up backend services or mock APIs over network.
- **Strict Extraction**: Only extract and clean existing UI components. Do not copy external source code, perform unprompted redesigns, or introduce new layout bugs.
- **Aesthetic Integrity**: You are forbidden from modifying typography, grid values, spacing, or CSS responsive structures unprompted. 
- **Accessibility**: All interactive elements must support proper semantic keyboard navigation and focus trapping.
